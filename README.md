# Тамагочи на C++

Консольная игра-тамагочи с ASCII-графикой. Учебный проект по полиморфизму:
базовый класс `Pet` и наследники `Cat`/`Dog`, функция `renderPet(Pet*)` —
демонстрация виртуальных вызовов через указатель на базовый класс.

## Сборка

CMake:

```sh
cmake -B build -S .
cmake --build build
./build/tamagotchi
```

Или

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic -Iinclude \
    src/*.cpp -lncursesw -o tamagotchi
./tamagotchi
```

## Как играть

1. Выбираешь питомца — кота или собаку.
2. Даёшь имя.
3. На каждом ходу видишь арт питомца, полоски характеристик и меню действий:
   покормить, напоить, поиграть, уложить спать, выйти.
4. После каждого хода некоторые характеристики ухудшаются, а некоторые улучшаются. Питомец умирает, когда HP
   падает до нуля.

Состояния (`MoodState`): `Happy`, `Neutral`, `Sad`, `Sick`, `Dead` — изображение
питомца меняется в зависимости от состояния.

## ТЗ
1) реализовать базовый класс Pet  с полями 
```
    int hp;
    int hunger;
    int thirst;
    int mood;
    int energy;
    int age;
```

и с методами, присущими каждому из питомцев: 
```
   void feed() - покормить
   void drink() - напоить
   void play() - поиграть
   void sleep() - поспать
   void tick() - обновление состояния (тик времени)
```

Виртуальные методы
```
   virtual std::string voice() const = 0 - голос питомца
   virtual std::string species() const = 0 - вид питомца
   virtual std::string specialActionName() const = 0 - название особого действия
   virtual void specialAction() = 0 - особое действие
   virtual std::string getAsciiArt() const = 0 - получить ASCII-арт
```

2) реализовать 2 класса-наследника: Cat и Dog. Методы классов-наслдеников оверрайдят методы бызового класса

3) реализовать минимальный пользовательский интерфейс через ncurses
