# Тамагочи на C++

Консольная игра-тамагочи с ASCII-графикой. Учебный проект по полиморфизму:
базовый класс `Pet` и наследники `Cat`/`Dog`, функция `renderPet(Pet*)` —
демонстрация виртуальных вызовов через указатель на базовый класс.

## Сборка

CMake:

```sh
cmake -B build -S .
cmake --build build
./build/tamagotchi
```

Или

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic -Iinclude \
    src/*.cpp -lncursesw -o tamagotchi
./tamagotchi
```

## Как играть

1. Выбираешь питомца — кота или собаку.
2. Даёшь имя.
3. На каждом ходу видишь арт питомца, полоски характеристик и меню действий:
   покормить, напоить, поиграть, уложить спать, особое действие, выйти.
4. После каждого хода характеристики ухудшаются. Питомец умирает, когда HP
   падает до нуля.

Состояния (`MoodState`): `Happy`, `Neutral`, `Sad`, `Sick`, `Dead` — арт
питомца меняется в зависимости от состояния.
